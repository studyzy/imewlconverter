# 本文主要介绍词汇的编码

## 示例

code_e2=p11+p12+p21+p22

code_e3=p11+p21+p31+p32

code_a4=p11+p21+p31+n11

## 说明

code_e{n}是说 n 个字的时候的编码规则
p{x}{y} 表示第 x 个字的第 y 个编码
取最后一个字的第 1 码用 `n11`（`n` 表示倒序取字，第 1 个数字是倒数第几个字，末位数字是码序号）

## 举例

我们有个编码规则，在 4 个字或者更多字的时候取前 3 个字的第一码，以及最后一个字的第一码，那么我们的规则表达式写为：
**code_a4=p11+p21+p31+n11**
